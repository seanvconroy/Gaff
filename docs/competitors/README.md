# Competitor teardowns

A bank of competitor UX flows, kept for reference so we can build something much better. Each competitor has a folder with its screenshots in `images/` and one file per flow.

Notes here record what we saw, not what to do about it. Decisions belong in the PRD, ADRs or `open-questions.md`.

## How to add a teardown

1. Put screenshots in `docs/competitors/<competitor>/images/`, numbered in flow order (`01-…`, `02-…`).
2. Add or extend `<competitor>/<flow>.md`: the date captured, who the flow is for, then each step with its screenshot and what we observed.
3. Add a row to the index below.
4. No real personal data: crop or blur names, phone numbers and emails before committing.
