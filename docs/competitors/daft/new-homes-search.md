# Daft.ie: new homes search results

Captured November 2026. Desktop, full-page screenshot. For renters and buyers browsing new developments in Dublin.

![New homes results, full page](images/01-new-homes-results.webp)

## Observations

- Header with search filters, then a long single-column list of developments under "1,xxx Properties in Dublin" (count unreadable at this size).
- Each card: developer or agent branding bar in the developer's colour, a large hero photo, the development name and address, then two to three unit rows (thumbnail, price, beds and type).
- Display ads for Cars.ie (a sister site in the Distilled group) above the list, in a right-hand rail and inline every few cards. The ads are styled much like listing cards.
- A save (heart) icon on each card.
- The page is long; there is no map in view and no visible way to compare developments side by side.
